**Q：本地引擎需要什么硬件？**
Apple Silicon Mac（M1 及以上）。模型经 MLX 在 GPU 上推理，Intel Mac 请用远程 API 或 Edge TTS。

**Q：模型下载很慢 / 失败？**
默认已走 hf-mirror.com 镜像；也可用环境变量 `HF_ENDPOINT` 指定其他镜像端点，或手动下载后通过「模型位置」选择本地目录。

**Q：桌面窗口里界面显示异常（旧版样式、按钮无响应）？**
升级代码后首次启动会自动清理缓存自愈。若仍有问题，用 `uv run python main.py --gui browser` 走系统浏览器验证，并重启应用。

**Q：录音按钮没反应 / 麦克风被拒绝？**
macOS 需两层授权：① 应用内的浏览器内核授权；② 系统设置 → 隐私与安全性 → 麦克风，允许 Python/应用使用麦克风。仍失败可用「导入文件」兜底。

**Q：高亮和语音对不上？**
换过模型或改过文本后分块会变化，重新载入当前文件即可对齐；必要时勾选「全部重新生成」。

**Q：换音色后要全部重听一遍吗？**
不用。已合成的部分照常复用，新音色从上次位置继续生成；只有「全部重新生成」才会清空重来。

**Q：播放没生成完的章节会怎样？**
直接播放即可：已就绪的段落立刻开播，应用同时在后台自动继续生成剩余音频，生成到哪、听到哪，无需手动点「开始生成」。模型缺失或生成启动失败时不会自动触发，此时可手动开始。

**Q：切走再回来，上次的收听位置会丢吗？**
不会。进度按文件（章节）分别记忆，切回时恢复上次位置并居中闪烁提示；重启应用同样续播。「连续播放自动跳章」是例外——新章从章首播放，保证与上一章内容接续。

**Q：数据存在哪里？**
默认 `~/.Auroravoice`（书籍元数据、音频缓存、设置、模型、克隆参考）。可在首次启动向导中更换。

**Q：支持哪些文本格式？**
`.txt` 纯文本。把若干 `.txt` 放进一个文件夹即是一本书。
