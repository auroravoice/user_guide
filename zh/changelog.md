按版本倒序记录主要更新（新功能与修复）。

## v1.0.7 · 2026-09-06

「听书不断流」——这一版集中解决播放未完成章节时的续听与进度记忆。

### 新增

- **自动续生成**：播放尚未生成完的章节时，应用会自动在后台继续补齐剩余音频，同时先播放已就绪的段落，生成到哪、听到哪，不再需要手动点「开始生成」；成功启动后台生成时会弹一条短提示
- **自动切章也续生成**：连续播放跨章后，若新章音频未生成完，同样自动触发续生成（用户默认要播完）
- **进度按文件记忆**：每章的阅读位置、段内偏移与书签单独保存。切走再回来会恢复上次位置并居中定位、短暂闪烁提示；重启应用同样续播。自动跳章则例外——即使新章曾有半章进度也从章首播放，保证与上一章内容接续

### 修复

- 播放遇未生成段不再直接跳到下一章：置等待态自动触发生成，音频就绪即自动续播（等待与用户主动暂停严格区分）
- 旧版本遗留音频缺少切分记录时，首次合成自动按当前切分重建记录，此后精确复用、不再误重生成
- 切章后文本区滚动归零，不再残留上章底部位置导致新章画面全白

## v1.0.6 · 2026-08-25

- 跳过 scipy 调用 Accelerate 私有 LAPACK/BLAS 符号的路径，满足 App Store 合规要求

## v1.0.0 · 2026-08-22

首个正式版本：

- **本地推理**：基于 MLX 在 Apple Silicon 上本地合成，文本不出本机
- **声音克隆**：应用内录音或导入音频，几十秒创建专属音色
- **边生成边听**：逐块合成、即时播放，断点续合复用已生成段落
- **多引擎**：本地 MLX / 远程 API / Edge TTS 切换
- **双语界面与主题**：中文 / English，5 个预设主题
- **进度记忆**：自动保存阅读位置，重启续播
