曦光聆（Auroravoice）是一款本地运行的 macOS 桌面应用。我们设计的核心原则是：**你的文字和声音只属于你**。

## 我们收集的信息

- 不需要注册账户，不收集任何个人信息
- 应用内置无遥测、无埋点、无崩溃上报
- 官网托管在 GitHub Pages，GitHub 可能按其自身政策记录标准访问日志（如 IP 地址、访问时间），与本应用无关

## 文本与音频数据

- **本地引擎（MLX，推荐）**：文本切分、语音合成全部在你的 Mac 上完成，任何文本、音频都不会离开设备
- **声音克隆**：你朗读的样本或导入的音频仅保存在本机，用于生成专属音色，不会上传
- **阅读进度与设置**：保存在本机，卸载应用即随之删除

## 可选的第三方引擎

以下引擎为可选项，默认不启用：

- **远程 API**：若你在设置中填入自己的 API 服务商，文本会发送到该服务商进行合成，数据处理受其隐私政策约束
- **Edge TTS**：文本会发送到微软服务器合成语音，处理方式见微软隐私声明；使用前请自行评估

使用以上任一云端引擎前，应用会明确提示。

## 儿童隐私

本应用不面向儿童收集任何信息，也不存在信息收集行为。
