# 使用指南

## 1. 打开书籍

- 点击侧栏「打开书籍」，选择一个文件夹（里面的 `.txt` 文件会被识别为章节/文件）
- 「最近」列表会显示最近打开过的书籍，一键直达
- 也可以在启动时用 `--book` 参数直接打开

## 2. 选择文件并生成朗读

1. 在左侧文件列表选择要朗读的文本
2. 在侧栏选择引擎和音色
3. 点「开始生成」——应用会把文本智能分块、逐块合成
4. 进度条实时推进；**已完成的块立即可听**，不必等全部完成

> 中断后再次点「开始生成」会从上次位置继续，已完成的部分不会重复合成。

## 3. 播放控制

| 操作 | 效果 |
|---|---|
| 播放 / 暂停 | 控制当前段落 |
| 单击文字 | 加下划线标记 |
| 双击文字 | 从该处开始播放 |
| 速度滑杆 | 0.5x ~ 2.0x |

当前正在朗读的句子会高亮显示，段落编号在其所有内容就绪后变绿。

## 4. 全部重新生成

换音色后默认**继续生成**（保留已有部分）。如果想按新设置从头重做，勾选「全部重新生成」再点开始。

## 5. 进度自动保存

每 5 秒自动保存当前文件、段落与播放位置；暂停/停止/切换文件时也会立即保存。下次启动自动恢复到上次的阅读进度。

## 6. 设置

设置对话框里可以调整：

- **语言 / 主题 / 字体 / 字号 / 行距**（改动即时预览，「保存」才生效）
- **模型位置**：使用本机已有的其他模型（即时生效）
- **关于**：查看版本信息
